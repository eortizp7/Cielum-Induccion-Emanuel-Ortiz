# Cielum - Inducción Desarrollo (version main)



Repositorio de práctica para el plan de inducción de 3 semanas en el área de Desarrollo de Software.



## Autor



Emanuel Ortiz



## Contenido



- `entorno.md`: registro de las versiones de herramientas instaladas en el entorno de desarrollo local.

- `bitacora/`: registro diario de actividades realizadas durante el plan de inducción.



## Plan



Este repositorio se irá actualizando día a día durante las 3 semanas del plan de inducción, documentando el progreso, los ejercicios realizados y las lecciones aprendidas.
